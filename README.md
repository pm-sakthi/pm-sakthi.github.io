# Sakthivel P — 3D Infrastructure Portfolio

A responsive, static portfolio for GitHub Pages with a CSS 3D server rack scene, animated canvas network, interactive simulated terminal, technical skill cards, experience timeline and direct contact links.

## Preview
Open `index.html` in a modern browser. Google Fonts require an internet connection, but fallback fonts are provided. No build tools, API keys or backend needed.

## Publish to GitHub Pages
1. Extract the ZIP.
2. Open the GitHub repository `pm-sakthi.github.io`.
3. Upload the **contents** of the `sakthivel-3d-portfolio` folder (`index.html`, `style.css`, `script.js`) to the **root** of the repository, replacing older versions if appropriate.
4. Commit the changes.
5. In repository Settings → Pages, select Deploy from a branch, your default branch, and `/ (root)`.
6. Open https://pm-sakthi.github.io/ after deployment finishes.

## Customize
- Edit text, experience, skills and contact links in `index.html`.
- Change colors in the `:root` variables at the beginning of `style.css`.
- Edit simulated terminal responses in `script.js`.
- The network visualization and server racks are **conceptual**, not connected to real monitoring data.

## Resume accuracy
Experience, education, skills and contact details are based on the uploaded `SAKTHI_CV.pdf`. No fabricated projects, certifications, employer outcomes, uptime percentages or social profiles are included. The "available to connect" label indicates contact availability, not verified job-seeking status.

## Privacy
The site publicly displays the email and phone from the resume. Remove the phone link from `index.html` before publishing if you do not want it public.
